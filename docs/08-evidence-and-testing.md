# Evidence and Testing

## Evidence hierarchy

Strong evidence may include:

1. confirmed transaction failure
2. repeated customer support question
3. usability observation
4. analytics pattern
5. session recording
6. technical error
7. heuristic concern

A heuristic concern is still useful, but label it honestly.

## Finding language

Use:

> This may increase friction because...

Avoid:

> This is definitely losing 30% of sales.

Unless the number is directly supported by reliable evidence.

## Before-and-after validation

Possible success measures:

- checkout completion rate
- product-to-cart rate
- cart-to-checkout rate
- payment success rate
- field error rate
- mobile CTA interaction
- inquiry response time
- recovery stage progression
- support-question frequency

## Testing methods

- analytics comparison
- event tracking
- usability testing
- A/B testing
- support-log review
- checkout-error review
- performance monitoring
- controlled staged rollout

## Avoid false certainty

A change can coincide with improvement without being the only cause. Record:

- date
- traffic source changes
- campaign changes
- stock changes
- pricing changes
- seasonality
- technical releases
