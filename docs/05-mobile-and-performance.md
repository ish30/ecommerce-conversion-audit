# Mobile and Performance

## Mobile-first review

Most e-commerce journeys should be tested at common mobile widths before desktop conclusions are accepted.

## Mobile checks

- header does not consume excessive space
- menu is easy to open and close
- search is visible
- text is readable
- buttons are easy to tap
- no horizontal overflow
- forms use appropriate input types
- validation is visible near the field
- images do not push actions too far down
- CTA remains easy to find
- sticky elements do not cover content
- checkout works without zooming

## Performance checks

- homepage load
- product image weight
- layout shift
- script errors
- slow third-party widgets
- unnecessary redirects
- broken assets
- oversized banners
- cache behavior
- slow checkout requests

## Evidence

Performance findings should include:

- device and network condition
- page tested
- repeated observation where possible
- waterfall or browser evidence when available

Avoid presenting one synthetic score as the whole user experience.
